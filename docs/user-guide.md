# 植物病害智能检测系统 - 使用指南

## 一、系统概述

本系统是基于 YOLOv11 深度学习模型的植物病害智能检测平台，采用前后端分离架构（Vue 3 + Django），支持用户上传植物叶片图片，自动识别病害类型并给出检测结果。系统集成了数据集管理、模型训练、实验评估和知识库等功能，可服务于农业科研人员、植物保护工作者及相关专业学生。

主要特性：
- 支持 27 类植物病害的智能检测（基于 FieldPlant 数据集）
- 完善的用户管理与权限控制
- 知识库系统提供病害防治参考
- 实验结果可视化，适合论文撰写
- 管理员后台支持系统运维

## 二、账号管理

### 2.1 用户注册

1. 在登录页面点击 **「注册」** 切换到注册表单
2. 填写以下信息：
   - **用户ID**：2~20 个字符，支持中英文、数字、下划线（注册后不可修改，用于登录）
   - **昵称**：1~20 个字符（选填，用于系统内展示，可随时修改）
   - **手机号**：11 位有效手机号码
   - **密码**：至少 8 位，必须包含大写字母、小写字母和数字
   - **确认密码**：与密码一致
3. 勾选 **「我已阅读并同意服务条款」**
4. 点击 **「注册」** 按钮完成注册
5. 注册成功后自动跳转到登录页面

> ⚠️ 用户ID注册后不可修改，请谨慎填写。昵称可在个人中心随时修改。

### 2.2 用户登录

1. 输入 **用户ID** 和 **密码**
2. 输入 **图形验证码**（点击验证码图片可刷新）
3. 可选勾选 **「记住我」**（勾选后 7 天内免登录）
4. 点击 **「登录」** 按钮

> ⚠️ 连续 5 次登录失败将触发登录锁定，需等待 60 秒后重试。

### 2.3 忘记密码

当忘记登录密码时，可通过以下步骤重置：

1. 在登录页面点击 **「忘记密码？」** 链接
2. 在忘记密码页面填写以下信息：
   - **用户ID**：注册时使用的用户ID
   - **手机号**：注册时绑定的手机号码
   - **新密码**：至少 8 位，必须包含大写字母、小写字母和数字
   - **确认新密码**：与新密码一致
   - **图形验证码**：输入图片中显示的验证码
3. 点击 **「重置密码」** 按钮
4. 重置成功后跳转到登录页面，使用新密码登录

> 💡 系统通过用户ID + 手机号双重验证确认身份，请确保手机号与注册时一致。

### 2.4 退出登录

点击页面右上角的 **用户头像**，在下拉菜单中选择 **「退出登录」**，系统将清除登录状态并跳转到登录页面。

## 五、病害检测

### 5.1 上传图片

1. 进入 **「病害检测」** 页面
2. 通过以下方式上传图片：
   - **拖拽上传**：将图片文件拖拽到上传区域
   - **点击上传**：点击上传区域，在文件选择器中选择图片
3. 支持的图片格式：**JPG、PNG**
4. 图片大小限制：**最大 10MB**
5. 上传后系统自动调用 YOLOv11 模型进行推理

### 5.2 查看检测结果

检测完成后页面展示以下信息：

- **检测标注图**：原图上叠加检测框，标注病害位置
- **病害名称**：检测到的病害中文名称
- **植物名称**：识别出的植物种类
- **置信度**：模型对检测结果的置信度（0~1）
- **检测框详情**：每个检测框的坐标、类别和置信度

> 💡 检测结果自动保存到历史记录中，无需手动保存。

## 八、实验结果

### 8.1 训练曲线

展示模型训练过程中的损失和性能指标变化：

- **损失曲线**：
  - `train_box_loss`：训练集边界框损失
  - `train_cls_loss`：训练集分类损失
  - `val_box_loss`：验证集边界框损失
  - `val_cls_loss`：验证集分类损失
- **性能曲线**：
  - `mAP50`：IoU=0.5 时的平均精度
  - `mAP50-95`：IoU=0.5~0.95 的平均精度
  - `Precision`：精确率
  - `Recall`：召回率

### 8.2 评估指标

展示模型在测试集上的整体评估指标：

| 指标 | 说明 |
|------|------|
| mAP@0.5 | IoU=0.5 时各类别平均精度的均值 |
| mAP@0.5:0.95 | IoU 从 0.5 到 0.95 的平均 mAP |
| Precision | 精确率（预测为阳性中实际为阳性的比例）|
| Recall | 召回率（实际为阳性中被检测到的比例）|
| F1-Score | Precision 与 Recall 的调和平均 |

同时展示 **各类别 AP（Average Precision）** 值，便于分析模型对不同病害的检测能力。

### 8.3 模型信息

展示当前部署模型的详细信息：

- **模型路径**：模型文件在服务器上的存储位置
- **模型版本**：使用的 YOLOv11 预训练模型版本（如 yolo11n.pt）
- **类别数量**：模型支持检测的病害类别数（29 类）
- **模型文件大小**：权重文件体积
- **输入分辨率**：模型输入图像尺寸（640×640）

### 11.3 数据集准备

#### 方式一：手动下载后转换（推荐）

1. 访问 https://universe.roboflow.com/plant-disease-detection/fieldplant/dataset/11 下载 FieldPlant 数据集（YOLO 格式）
2. 解压后目录结构为：`train/images/`, `train/labels/`, `valid/images/`, `valid/labels/`, `test/images/`, `test/labels/`
3. 运行转换脚本（自动检测预划分目录，保留 test 集，从 train 中拆分出 val 集）：

```bash
python yolo/prepare_dataset.py --source /path/to/FieldPlant.v11
```

#### 方式二：兼容 PlantDoc 数据集

```bash
python yolo/prepare_dataset.py --source /path/to/plantdoc_raw --dataset plantdoc
```

> **说明**: 如需使用旧版 PlantDoc 数据集，可通过 `--dataset plantdoc` 参数指定。

#### 验证数据集

```bash
python yolo/prepare_dataset.py --validate
```

验证通过后，数据集将按以下结构存放：

```
datasets/plant_disease/
├── images/
│   ├── train/    # 训练集图片
│   ├── val/      # 验证集图片
│   └── test/     # 测试集图片
└── labels/
    ├── train/    # 训练集标注（YOLO TXT 格式）
    ├── val/      # 验证集标注
    └── test/     # 测试集标注
```

## 十二、常见问题

**Q：模型文件不存在怎么办？**

A：系统会自动返回模拟数据，不影响其他功能使用。将训练好的 `best.pt` 放到 `model/` 目录即可恢复正常检测功能。

**Q：忘记用户ID怎么办？**

A：请联系系统管理员，管理员可以在用户管理页面查询所有注册用户信息。

**Q：如何获取管理员权限？**

A：请联系现有管理员，在管理后台的用户管理中设置管理员权限。首个管理员账号可通过命令行创建：`python manage.py create_admin --username admin --password admin123`。

**Q：上传图片后显示检测失败怎么办？**

A：请检查以下几点：
1. 图片格式是否为 JPG 或 PNG
2. 图片大小是否超过 10MB
3. 模型文件 `model/best.pt` 是否存在
4. 查看后端控制台是否有报错信息

**Q：数据集管理和模型训练页面无法访问？**

A：这两个功能仅对管理员开放。请确认当前账号拥有管理员权限（`is_admin=1`）。如需权限请联系管理员。

**Q：如何进行论文实验？**

A：建议在模型训练管理页面参考实验设计建议，包括：
1. **不同模型对比实验**：使用 yolo11n/s/m/l/x 不同规模模型训练并对比指标
2. **训练策略对比实验**：使用预定义策略（基线/增强/微调/轻量化/论文优化）进行系统化对比
3. **消融实验**：调整 epochs、batch size、学习率等超参数观察影响
4. **数据增强实验**：对比不同数据增强策略的效果
5. **论文优化策略**：使用 `--strategy thesis` 综合 AdamW 优化器、学习率预热、标签平滑、CopyPaste 增强等最佳实践

实验结果页面提供训练曲线和评估指标的可视化展示，可直接用于论文图表。
